## Run the swap form

```sh
cd src/problem2
npm ci
npm run dev
```

Open the local URL printed by Vite. The form uses the challenge’s price feed and simulates swaps; it does not connect to a wallet or move funds.

Use Node.js 22.12+ or a supported newer release. The solution files explain their assumptions. Problems 4 and 5 belong to other tracks and retain their original placeholders.
